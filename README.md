# Chaos, Fractals, and Dynamical Systems

This is the software repository for the PhD course on [Chaos,
Fractals, and Dynamical
Systems](https://www.moreno.marzolla.name/teaching/chaos-fractals/2025-2026/),
Department of Computer Science and Engineering, University of Bologna,
Italy.

The following programming languages or environments are used:

- [Jupyter notebooks](https://jupyter.org/).
- [GNU Octave](https://octave.org/).
- [NetLogo](https://www.netlogo.org/).
- [GeoGebra](https://www.geogebra.org/classic).

# The Lorenz system

This directory contains [GNU Octave](https://www.octave.org/) scripts
to solve the Lorenz system. The original author is [John
Burkardt](https://people.sc.fsu.edu/~jburkardt/octave_src/lorenz_ode/lorenz_ode.html)
who released the source code under an open source license.

To run, execute `lorenz_test.m`

```bash
octave lorenz_test.m
```
